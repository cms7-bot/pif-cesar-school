a) While: condição é avaliada antes da execução do bloco de código. Se a condição for falsa logo na primeira verificação, o laço é ignorado e o código dentro dele é executado zero vezes. Do while: o bloco de código é executado primeiro, e a condição é avaliada apenas no final da iteração. Isso garante que o bloco será executado pelo menos uma vez, mesmo que a condição de teste seja inicialmente falsa.

b) For: é mais adequado quando sabemos previamente quantas vezes o bloco de código deverá ser repetido. É muito utilizado para percorrer arrays, listas e realizar repetições com um contador. Exemplo: executar um código 10 vezes. While: é mais adequado quando não sabemos exatamente quantas vezes a repetição ocorrerá, mas temos uma condição que determina quando ela deve continuar. A condição é verificada antes de cada repetição. Exemplo: continuar solicitando uma senha enquanto ela estiver incorreta. Do while: é adequado quando precisamos garantir que o bloco de código seja executado pelo menos uma vez, pois a condição é verificada somente depois da execução. Exemplo: exibir um menu para o usuário e continuar exibindo-o enquanto ele não escolher a opção de sair.

c) O trecho while (condicao); é um erro de lógica. O código é compilado com sucesso (sem erros sintáticos) porque a linguagem C reconhece o ponto-e-vírgula isolado como uma "instrução nula" ou comando vazio.
