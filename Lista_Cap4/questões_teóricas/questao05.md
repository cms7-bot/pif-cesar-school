a) A saída exata gerada pelo comando printf será a = 0, b = 5, c = 8. O incremento ++b foi ignorado. Como a variável a vale 0, a primeira expressão lógica (a != 0) é avaliada como falsa. Pela regra de curto-circuito do operador &&, a segunda parte da condição (++b > 5) não precisa ser avaliada, impedindo que a variável b seja incrementada e mantendo seu valor em 5. Por ser falsa, o fluxo entra no bloco else, reduzindo c em 2 (passando de 10 para 8)

b) Ocorre quando o compilador interrompe a leitura de uma expressão lógica assim que o resultado final já está garantido pela primeira condição.   Para o operador E (&&): Se o primeiro operando for falso, a expressão inteira será falsa independentemente do restante. Portanto, o segundo operando é completamente ignorado.   Para o operador OU (||): Se o primeiro operando for verdadeiro, a expressão inteira será verdadeira. Portanto, o segundo operando também é ignorado. 

c) Os valores finais seriam b = 5 e c = 20. Nesta nova condição, a primeira parte (a == 0) resulta em verdadeiro. Devido ao efeito de curto-circuito do operador ||, a segunda avaliação (++b > 5) é descartada pelo compilador. Assim, b não sofre incremento e permanece 5. Como a estrutura if foi validada como verdadeira, o programa executa c += 10, elevando o valor de c de 10 para 20.
